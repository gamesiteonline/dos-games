# Gamesiteonline - 6 Game Download Websites

## Project Overview
Building 6 separate, independently deployable skeuomorphic game download websites:
1. DOS Games (dos-games-site)
2. Mobile Games (mobile-games-site)
3. Xbox 360 (xbox360-games-site)
4. PS1/PSX (ps1-games-site)
5. PC/Dreamcast (pc-dreamcast-games-site)
6. PS3/PS4 (ps3-ps4-games-site)

Owner: Fahad | Company: Gamesiteonline | Location: Tanzania

## Shared Features (All Sites)
- [ ] Skeuomorphic UI design system with platform-specific themes
- [ ] Game catalog page with grid/list view
- [ ] Genre and platform filter bar
- [ ] Search bar with instant client-side filtering
- [ ] Game detail modal/page
- [ ] AN1-style in-site download flow (countdown + direct download)
- [ ] Pagination/infinite scroll for large datasets
- [ ] Footer with owner info and social media links
- [ ] Fully responsive layout (desktop + mobile)
